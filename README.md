A high-performance, developer-first personal portfolio and interactive resume designed for **Kataru Rahul Reddy** (Computer Science undergraduate at Nitte Meenakshi Institute of Technology, Bengaluru). Built with **Next.js App Router**, **Framer Motion**, **Tailwind CSS v4**, and **Lenis inertial smooth scrolling**, matching the visual rhythm, dark kinetic aesthetics, and micro-interactions of modern elite design portfolios.

---

## 🚀 Key Features

### 1. 3D Fanned Poster Ring Hero
- 11 project posters dynamically fanning out in 3D perspective space with interactive tilt tracking and auto-rotation.
- Real-time **Bangalore Local Time (IST)** clock with a live pulsing availability beacon.
- Giant high-impact typography with subtle vertical gradient masks.

### 2. Scroll-Illuminated Biography & Dev Mode
- Word-by-word scroll illumination matching reference mechanics.
- Interactive keyword color blooming on milestone phrases (`churn predictions`, `document intelligence`, `safety detection`, `Python and SQL`).
- **Dual-View Toggle**: Switch seamlessly between natural story mode and a syntax-highlighted Python class (`rahul_reddy.py`) with 1-click code copying.

### 3. Sticky 3D Stacking Project Cards & Deep Dive Case Studies
- Sticky deck-stacking cards with increasing `topOffset`.
- Real verified project telemetry (83.16% recall, 0.8346 ROC-AUC, 37 test cases, 30+ FPS edge vision).
- **Interactive ML Churn Simulator**: Run live client risk predictions in browser with interactive sliders and retention playbooks.
- **Deep Dive Technical Modal**: In-depth architecture breakdowns, sequence flow, and FastAPI backend code with isolated `data-lenis-prevent` scrolling.

### 4. Interactive Services & In-Browser SQL Playground
- Clean high-contrast cards for Machine Learning, Data Science, Backend & Frameworks, Databases, and Tools.
- In-browser SQL console executing real queries against in-memory datasets (`telco_customers`, `document_records`, `driving_telemetry`).

### 5. Creative Lab & Archived Adventures
- Infinite horizontal project marquee with retro pixel badges.
- Tabular archive vault tracing engineering projects from 2025 to 2026.

### 6. Comprehensive Interactive Resume (`/resume` & In-Page Modal)
- Dedicated `/resume` page with two view modes:
  - **Modern Visual Mode**: Dark theme with glassmorphism cards and live status indicators.
  - **Executive ATS Mode**: Clean monochrome paper layout formatted for ATS scanners.
- In-page interactive modal triggered directly from the Navbar "Resume" button.
- 1-click contact copying, Print/PDF export (`window.print()`), and direct download link to Google Drive PDF.

## 💻 Local Development

```bash
# Clone the repository
git clone https://github.com/nmit-1NT23CS105/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start the local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the portfolio.

---

## 📦 Production Build

```bash
npm run build
npm start
```
